# /lecture — 강의 1회 기록

사용자는 한국어가 편하다. 모든 대화와 정리 노트는 한국어로 쓴다. 규칙의 핵심은 **전체 기록을 빠뜨리지 않는 것**이다.

## 1. 입력 확인

필요한 것: ① 과목 ② 날짜 ③ 슬라이드 PDF(없어도 진행 가능) ④ 녹음 파일 또는 녹취 텍스트. 녹음은 **여러 파일일 수 있다** (노트북 녹음 중 배터리가 나가 폰 녹음기로 이어 받은 경우 등). 각 파일이 시작된 대략의 시각과 이어진 슬라이드 쪽수를 알면 물어서 받는다.
인자나 대화에서 빠진 것만 한 번에 묻는다. 날짜를 말하지 않으면 오늘 날짜를 제안하고 확인한다.

- 과목은 `courses.yaml`에서 찾는다 (이름 일부만 말해도 된다). 없거나 `status: archived`이면 멈추고 추가·복원할지 묻는다. 임의로 만들지 않는다.
- 파일 경로는 절대경로로 받는다. 입력 파일은 읽기만 하고 수정·삭제하지 않는다.
- 같은 날짜의 기록이 이미 있으면 덮어쓰지 말고, 기존 내용을 읽은 뒤 무엇을 보강할지 사용자에게 알린다.

## 2. PDF에서 슬라이드 읽기

1. `pypdf`로 슬라이드별 텍스트를 뽑는다. 슬라이드 번호는 PDF 페이지 번호를 쓴다. (`pdftotext`는 PDF에 따라 한글이 통째로 빠지므로 `pypdf`를 먼저 쓴다. `python -I`로 돌릴 때는 출력이 cp949라 깨지니 `sys.stdout.reconfigure(encoding="utf-8")`를 쓴다.)
2. 텍스트가 거의 없는 페이지(이미지·도표)는 눈으로 봐야 한다. 이 PC에는 poppler(`pdftoppm`)가 없어 Read 도구의 PDF 페이지 렌더링이 되지 않는다. 필요하면 사용자 동의를 받고 `pymupdf`를 설치해 해당 페이지만 PNG로 렌더링해 읽는다.
3. 슬라이드 용어 목록(영문 용어, 학명, 약어)을 만든다. 녹취 교정의 기준이 된다.

PDF 원본은 **저장소에 올리지 않는다.** 공개 사이트이고 저작권이 있는 자료이기 때문이다. 사용자가 명시적으로 원할 때만 추가한다.

## 3. 녹취 만들기

- **텍스트 녹취가 있으면** 그대로 사용한다.
- **음성 파일만 있으면**(폰 녹음기 m4a/mp3 등) `faster-whisper`로 변환한다. 이 PC에는 설치돼 있다 (v1.2.1, GPU 없음 → CPU 실행, 파일 디코딩은 내장 PyAV라 ffmpeg 불필요).
  - 모델 가중치는 처음 쓸 때 내려받는다. 처음 실행 전에 모델 크기(예: `small` 약 0.5GB, `medium` 약 1.5GB)와 대략의 소요 시간을 사용자에게 알리고 진행한다. 한국어·영어 전문용어 정확도가 중요하므로 기본은 `medium`, 너무 느리면 `small`을 제안한다.
  - 언어는 자동 감지하되, 과목이 영어/한국어 어느 쪽인지 알면 `language`를 지정한다. 혼용 수업은 자동 감지에 맡기고 구간별로 언어를 기록한다.
  - 시각(`[mm:ss]`)이 포함된 구간 단위 텍스트로 받고 `vad_filter=True`로 무음 구간을 거른다. 긴 파일은 진행 상황을 보고하며 처리하고, 백그라운드로 돌린다.
  - **주의(이 PC에서 확인한 문제)**: `faster-whisper` 1.2.1의 내장 디코더가 `av` 19.x와 맞지 않아(`metadata_errors` TypeError) 파일 경로를 그대로 넘기면 실패한다. `av`로 직접 16kHz 모노 float32 배열로 디코딩해서 `transcribe()`에 배열을 넘긴다. 패키지 버전은 바꾸지 않는다.
  - 슬라이드의 전문용어를 `initial_prompt`에 넣으면 인식 정확도가 오른다. `condition_on_previous_text=False`로 반복 오류를 줄인다.
  - 결과 텍스트는 임시 폴더(scratchpad)에 저장하고, 입력 음성 파일은 건드리지 않는다.
- **녹음 파일이 여러 개이면** 파일 이름·수정 시각·사용자 설명으로 순서를 정하고 하나씩 변환한 뒤, 시각을 이어 붙인다(둘째 파일의 `[mm:ss]`에 앞 파일 길이를 더한다). 파일이 바뀌는 지점에는 `[녹음 전환: 파일2 시작]`을 남긴다. 끊긴 사이에 녹음되지 않은 시간이 있을 수 있으므로, 그 구간의 내용은 슬라이드로만 추정하지 말고 `[녹음 없음: 약 N분]`으로 표시해 사용자에게 알린다. 녹음이 이어진 앞뒤가 같은 내용으로 겹치면 한 번만 쓰되 겹침 처리를 보고한다.

## 4. 녹취 정제 (요약하지 않는다)

- 오탈자, 전문용어, 고유명사만 슬라이드 용어 기준으로 교정한다. 내용을 줄이거나 바꾸거나 재배열하지 않는다.
- 문단마다 시작 시각 `[mm:ss]`을 붙인다. 번역과 대응시킬 때 같은 시각을 쓴다.
- 들리지 않거나 확신이 없는 부분은 지어내지 말고 `[?]`로 남긴다.
- 한 번에 다 쓰려 하지 말고 10분 단위로 나누어 파일에 이어 쓴다. 길이 때문에 뒷부분이 잘리면 안 된다.

## 5. 언어별 처리

강의 언어를 판단한다: 한국어 / 영어 / 혼용(한 수업 안에서 섞임).

- **한국어**: 녹취 전문만 둔다.
- **영어**: 영어 녹취 전문을 쓰고, **바로 아래에 한국어 번역 전문**을 붙인다.
  - 번역은 요약이 아니라 전문 번역이다. 문단 수와 `[mm:ss]` 시각을 영어 녹취와 똑같이 맞춰 두 글을 대조할 수 있게 한다.
  - 전문용어는 `한국어(English)` 형태로 처음 나올 때 병기한다. 학명과 약어는 원문 그대로 둔다.
  - 번역이 어색하거나 확신이 없으면 `[번역 확인]`으로 표시한다.
- **혼용**: 영어로 말한 부분만 영어 원문과 번역을 함께 둔다. 한국어 부분은 그대로 둔다.

정리 노트(요약, 강의 흐름, 용어, 공지)는 언어와 관계없이 한국어로 쓰고, 핵심 용어는 영어 원어를 병기한다.

## 6. 페이지 작성

파일: `src/content/docs/{semester}/{course-id}/{YYYY-MM-DD}.md`. 틀은 `templates/lecture.md`를 따른다.

- `title`은 그날 강의 주제를 짧게. `description`은 한 줄 요약.
- **요약**: 핵심 3~5개.
- **강의 흐름**: 슬라이드 순서대로, 슬라이드 내용에 교수님이 구두로 덧붙인 설명을 합쳐 쓴다. 슬라이드 번호를 `슬라이드 3-7`처럼 남긴다.
- 교수님이 시험을 언급한 부분(범위, 유형, "중요하다", "나온다")은 반드시 `:::caution[시험 언급]` 블록으로 만들고 녹취 시각을 붙인다.
- **학생 발표**가 수업에 섞여 있으면(교수 강의가 끝난 뒤 발표 등) 강의 흐름과 섞지 말고 `## 학생 발표` 섹션을 따로 만든다. 발표마다 `### 발표자/팀 · 주제`를 두고 핵심 주장, 근거, 교수님의 질문·코멘트를 정리한다. 발표자의 이름·학번은 공개 사이트에 쓰지 않는다 (`발표 1 · 주제`처럼 번호와 주제만 쓴다). 발표 자료(PDF)가 있으면 그 내용과 녹취를 함께 근거로 쓴다. 사용자가 시험범위라고 알려준 발표는 각 발표 앞에 `:::caution[시험 범위]`로 표시하고 교수님 언급이 있으면 시각과 함께 남긴다. 발표 구간도 전체 녹취에 요약 없이 보존한다. 교수 강의와 발표의 경계 시각을 `[발표 시작]`으로 남긴다.
- **용어**, **공지**(휴강·시험·과제), **질의응답**은 해당 내용이 있을 때만 쓴다. 없는 섹션은 만들지 않는다.
- **일화·잡담**은 `<details>`로 접어 둔다. 학습과 무관해도 지우지 않는다.
- **전체 녹취**는 `<details>`로 접는다. 영어 강의면 영어 녹취 `<details>` 바로 아래에 `한국어 번역` `<details>`를 하나 더 둔다.
- 슬라이드에는 있으나 교수님이 다루지 않은 내용도 빠뜨리지 말고 흐름에 넣는다 (`강의에서는 다루지 않음` 표시).

## 7. 검증 (완료로 말하기 전에)

1. **슬라이드 커버리지**: PDF의 모든 페이지가 노트에 한 번 이상 반영됐는지 센다.
2. **녹취 커버리지**: 녹취의 처음~끝 시각이 이어져 있는지, 노트에 반영되지 않은 구간이 없는지 본다. 영어 강의는 영어와 번역의 문단 수가 같은지 센다.
3. `npm run build`가 성공하는지 확인한다.
4. 사용자에게 보고한다: 슬라이드 N/N, 녹취 길이, `[?]`·`[번역 확인]` 개수, 시험 언급 개수, 미반영 구간. 확인되지 않은 항목은 확인했다고 쓰지 않는다.

## 8. 게시

사용자 확인(승인)을 받은 뒤에만 한다.

1. `git add` 후 커밋 (메시지: `강의 기록: {과목} {YYYY-MM-DD}`).
2. `git push` — main에 푸시되면 GitHub Actions가 자동 배포한다.
3. 배포가 끝나면 페이지 주소를 알려준다: `https://ccongdde.github.io/snu-lecture-vault/{semester}/{course-id}/{YYYY-MM-DD}/`

## 하지 않는 것

- 녹취를 요약본으로 대체하거나 일부를 생략하지 않는다.
- 들리지 않은 부분, 슬라이드에 없는 사실을 지어내지 않는다.
- 입력 파일을 수정하지 않는다. PDF 원본과 녹음 파일은 저장소에 올리지 않는다.
- 승인 없이 푸시하지 않는다.
